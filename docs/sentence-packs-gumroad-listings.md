## Click-by-click (do Starter first, then repeat for 2–6)

Wording may vary slightly with Gumroad updates, but the flow is:

1. Log in at **gumroad.com** → top nav **Products**.
2. Click **+ New product** (top right).
3. In the popup:
   - **Name:** `Starter Sentence Pack`
   - **Type:** choose **Digital product**
   - **Price:** `6.99`  (leave currency USD; do **not** tick "pay what you want")
   - Click **Next: Customize**.
4. You're now in the editor, on the **Product** tab:
   - **Description box:** paste the Description block for this pack (it already opens
     with a bold hook line — that's your summary).
   - **Cover:** click **Insert / Upload** → add
     `C:\Users\kitme\CILI - Landing Page\src\assets\sentence-pack.png`.
     (Optional: also add `SentencesPack\SentencePackPdf_PNGs\<pack>\001.png`–`003.png`
     as extra preview images.)
   - **Thumbnail** (small square in listings): the same `sentence-pack.png` is fine.
5. **Set the permalink (the critical step):** find the product URL near the top —
   it looks like `cililearnchinese.gumroad.com/l/xxxxx`. Click the edit/pencil and
   change the slug to **exactly** `starter-sentences`. Save.
6. Switch to the **Content** tab → **Upload files** → add the 4 files from
   `SentencesPack\`:
   - `CILI Sentence Mastery - FOUNDATION 1K.pdf`
   - `CILI Sentence Mastery - FOUNDATION 1K.tsv`
   - `CILI Sentence Mastery - FOUNDATION 1K.json`
   - `LICENSE.txt`
7. Click **Publish** (top right).
8. Verify the live URL is exactly:
   `https://cililearnchinese.gumroad.com/l/starter-sentences`

Then repeat steps 2–8 for packs 2–6 below, swapping in their name / price /
permalink / description / files. **The permalink must match exactly each time** —
that's the only thing that breaks the website's Buy button.
